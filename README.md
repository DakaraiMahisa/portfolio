## 📖 Overview

This portfolio was designed to serve as my professional online presence.

Rather than being a simple landing page, it showcases my software engineering journey, enterprise projects, technical expertise, and provides recruiters with an interactive resume that can be downloaded as a professional PDF with clickable links.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/DakaraiMahisa/portfolio.git
```

Navigate into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
